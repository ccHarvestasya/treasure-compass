# 出力形式

この Skill のレビュー成果物は、`../review-common/output-format.md` の共通構成・章名・順序・
指摘必須項目を使用する。共通構成を省略、追加、並べ替えない。

## スキル固有の値

- 正式な指摘 ID 接頭辞: `RM`
- 重大度: `ERROR` / `WARN` / `NIT`
- レビュー結果: `READY` / `READY WITH MINOR FIXES` / `REVISE README`
- 必須修正: `ERROR` / `WARN` の New / Open / Reopened
- 任意改善: `NIT` の New / Open / Reopened
- 保留した指摘: README の責務を越える製品・仕様・実装上の事項、対象外文書、未決定事項
- 確認観点: Documentation、Examples、Links、Constraints、Security、Translation / Cross-document Parity
- 対象範囲と追跡: README、manifest、公開 API、実装、仕様、テスト、設定、package / release docs の対応
