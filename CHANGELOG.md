# Changelog

## [0.1.0] - 2026-09-13

### Added

- Treasure Compass の基本的なトレジャーハント巡回機能
- メンバー名と宝の地図地点の manual registration
- パーティチャットの bulk input
- `3.x`〜`7.x` の version-based filtering
- 巡回 route calculation と map / route display
- current target、完了／取消、`次へ`／`戻る` による progress management
- localStorage persistence
- responsive UI

### Changed

- チャットから取り込んだメンバー名の normalization を整理
- aetheryte label と route display を改善
